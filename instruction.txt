CHICKEN ON WHEELS - FIRST RUN INSTRUCTIONS

1. Requirements

Install these before starting:

- Node.js 18 or newer: https://nodejs.org/
- Python 3: https://www.python.org/downloads/
- A Supabase account: https://supabase.com/

2. Open the project folder

Open Terminal and change into the folder:

    cd path/to/chicken-on-wheels-vercel

For example:

    cd ~/Downloads/chicken-on-wheels-vercel

3. Install project dependencies

    npm install

4. Configure Supabase

Create a Supabase project, then:

1. Open Supabase SQL Editor.
2. Open supabase/schema.sql from this project.
3. Copy the entire file into the SQL Editor.
4. Run the SQL.
5. Confirm that profiles and booking_requests exist in Table Editor.

Enable email/password authentication in:

    Authentication -> Providers -> Email

For local development, set the Supabase Site URL to:

    http://localhost:3000

Open public/config.js and set:

    export const SUPABASE_URL = "your Supabase project URL";
    export const SUPABASE_PUBLISHABLE_KEY = "your publishable or anon key";

Use the publishable/anon key only. Never put a secret or service-role key in
public/config.js.

5. Start the website locally

    npm run dev / npx serve public

Open this address in a browser:

    http://localhost:3000

Do not open the HTML files directly with file://. They must be served through
the local web server. Stop the server with Ctrl+C.

6. Create a user account

Open:

    http://localhost:3000/login.html

Create an account and log in. If email confirmation is enabled in Supabase,
confirm the email before logging in.

7. Create an admin account

First create a normal user account. Then in Supabase SQL Editor run:

    update public.profiles
    set role = 'admin'
    where email = 'your-email@example.com';

Replace the email with the admin user's email address. Then open:

    http://localhost:3000/admin-login.html

Log in with that account. Admin users are redirected to admin.html.

8. Main pages

    Website:       http://localhost:3000/
    User login:    http://localhost:3000/login.html
    Dashboard:     http://localhost:3000/dashboard.html
    Admin login:   http://localhost:3000/admin-login.html
    Admin panel:   http://localhost:3000/admin.html

9. Troubleshooting

- If npm run dev says the command is missing, run npm install again and check
  that you are in the project folder.
- If the page is blank, use http://localhost:3000 instead of opening an HTML
  file directly.
- If login fails, check public/config.js and the browser console for errors.
- If tables are missing, rerun the entire supabase/schema.sql file.
- If the admin panel shows no requests, confirm the user's role is admin and
  that booking_requests contains rows.
